Help

  • The Top Pane All Songs: is all the songs, this is alphabetical and NOT sortable.
    Drag songs from here by their "handles ↑↓" to the lower Current Setlist pane.
    Once dropped there it will "dim" in All Songs so you don't select it again by mistake - you can however add a song again but it this case it will highlight in the Current Setlist pane so you can find both easily.

  • The lower pane Current Setlist: is basically that, you can re-oder them by dragging on their "handles ↑↓" and delete them from the list by clicking the "Trash Can 🗑" - deleting does NOT affect All Songs, only the Current Seltlist.

  • Load Setlists: is where you can find previously saved setlists, clicking "load" will temporarliy load into "Current Setlists" where it can be "edited", it only becomes permanant once you've saved it, refreshing the page before a save will return you to what it was when you started.
